# Welcome to VartaLang

VartaLang brings together language exchange, practical learning, and
language-linked opportunities. This documentation site is the starting point
for guides to the platform and its developer ecosystem.

The site structure is in place; detailed guides will be added next.

## Explore the documentation

- **Getting started** — account and profile guides.
- **Using VartaLang** — language exchange, jobs, learning, courses, and safety.
- **Platform architecture** — an overview of the VartaLang services.
- **For developers** — local setup, API references, and contribution guidance.
