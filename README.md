# VartaLang Documentation

The documentation site for VartaLang's platform, learning resources, and
developer ecosystem.

## Development

```bash
npm install
npm start
```

## Build

```bash
npm run build
```

## Documentation structure

- `docs/getting-started/` — getting started and account guides
- `docs/platform/` — platform features, learning, and safety
- `docs/architecture/` — services and platform architecture
- `docs/development/` — developer setup and API documentation

Pages are intentionally placeholders so content can be developed next.
